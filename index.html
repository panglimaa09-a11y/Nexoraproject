FAQ

Hal yang biasanya ditanyakan.

Apakah harga termasuk domain dan hosting?

Tidak otomatis. Domain, hosting, email bisnis, plugin premium, API berbayar dan layanan pihak ketiga dihitung sesuai kebutuhan.

Berapa kali revisi?

Client mendapatkan revisi selama masih dalam tujuan dan scope yang disepakati. Perubahan besar atau fitur baru dapat mengubah scope, harga dan estimasi.

Apakah bisa dibuatkan admin panel?

Bisa. Admin dashboard dapat masuk dalam Custom Web App atau quotation khusus.

Bagaimana pembayaran project?

Standar awal NEXORA adalah DP 30% dari quotation. Milestone dan pelunasan tercantum dalam quotation/invoice.
