## Deployment

This project is a static website and can be deployed directly to Vercel from the `main` branch.

### Vercel settings

- Framework Preset: **Other** (or leave auto-detected)
- Build Command: **None**
- Output Directory: **`.`**
- Install Command: **None**

The production entry point is `index.html`.
